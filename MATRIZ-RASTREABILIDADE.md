# Matriz de rastreabilidade

O [README.md](README.md), §§1–12, define comportamento e entrega. A [exportação local](DEV%20FRONT.png) do [Frontend Challenge](https://www.figma.com/design/Ff0SksUi7UFtPWUO8kyNtw/Frontend-Challenge?node-id=0-1) é a referência visual das nove telas desktop. Para mobile e tablet, o aceite verifica as adaptações responsivas e incorpora exportações adicionais caso estejam disponíveis.

Cada linha tem uma evidência exigida para o aceite. E01–E12 correspondem à numeração de cenários do §9. Todos os requisitos de implementação estão pendentes no ciclo 0. [Backlog](BACKLOG.md) · [Arquitetura e contratos](ARCHITECTURE.md).

## Bloqueios de aceite eliminatórios

O fechamento exige comprovar uso efetivo de toda a stack (R01), compra confirmada pela simulação e fluxos operacionais (R02–R11), isolamento de contas (R10), Socket.IO sem atalhos de UI (R14) e testes E2E executáveis (R17). O deploy público é obrigatório para a entrega (R20).
